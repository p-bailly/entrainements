Chapitre 3 · Nombres réels

Comment travailler. Chaque séance dure environ une heure. Ouvre les menus dans l'ordre : automatismes, cours, exercices. Garde ton cahier et ton manuel Indice 2de à côté de toi.

  • Les automatismes se font sans calculatrice, sur une feuille.
  • Le cours se recopie à la main dans le cahier. Les extraits s'ouvrent dans une fenêtre.
  • Pour chaque exercice, cherche d'abord seul(e). Si tu bloques, ouvre l'indication. N'ouvre la correction qu'après avoir écrit ta réponse, puis corrige-toi dans ton cahier.

Cours : parties 1 et 2 (entiers, décimaux)

À recopier dans le cahier.

Exercice 7 · manuel page 50
Indication

Une fraction décimale a pour dénominateur $10$, $100$, $1\,000$…

Pour chaque fraction, cherche par quel nombre multiplier le dénominateur pour obtenir $10$, $100$ ou $1\,000$, puis multiplie le numérateur par le même nombre. Si $10$ et $100$ ne sont pas des multiples du dénominateur, essaie $1\,000$ : par exemple $8\times 125 = 1\,000$.

Correction
Exercice 35 · manuel page 65
Indication

Un nombre est décimal s'il s'écrit $\dfrac{a}{10^{n}}$, c'est-à-dire si son écriture décimale a un nombre fini de chiffres après la virgule. Un entier est toujours décimal.

Pour une fraction, cherche une fraction égale de dénominateur $10$, $100$… Si tu n'y arrives pas, pose la division : si le même reste revient sans cesse, l'écriture ne s'arrête jamais.

Pour $\dfrac{\pi}{10}$, raisonne par l'absurde : si ce nombre était décimal, que pourrait-on dire de $\pi = 10\times\dfrac{\pi}{10}$ ?

Correction

Fiche d'exercices : exercice 4
Indication

Entre un nombre et un ensemble, on écrit $\in$ ou $\notin$ ; entre deux ensembles, on écrit $\subset$.

Simplifie d'abord chaque nombre : $\sqrt{16}$ peut s'écrire plus simplement, et pour $\dfrac{3}{5}$ cherche une fraction égale de dénominateur $10$.

Pour les listes, regarde les cas limites : $-3$ est-il exclu ou compris ? et $2$ ? Pour $x^{2} = 9$, cherche tous les entiers qui conviennent, positifs et négatifs, puis garde ceux qui sont dans l'ensemble demandé.

Correction
Exercice 1 · manuel page 50
Indication

Un nombre est décimal si son écriture décimale est finie. Les nombres écrits avec une virgule et un nombre fini de chiffres le sont.

Pour une fraction, cherche une fraction égale de dénominateur $10$, $100$, $1\,000$… Si tu n'y arrives pas, pose la division : si le reste n'est jamais nul et que les restes se répètent, l'écriture ne s'arrête jamais.

Correction
Exercice 34 · manuel page 65
Indication

Rappelle-toi les deux définitions : un décimal s'écrit $\dfrac{a}{10^{n}}$ ($a$ entier relatif, $n$ entier naturel) ; un rationnel s'écrit $\dfrac{a}{b}$ ($a$ et $b$ entiers relatifs, $b\neq 0$).

Si une affirmation te semble vraie, explique-la avec les définitions. Si elle te semble fausse, cherche un exemple qui la contredit.

Correction
